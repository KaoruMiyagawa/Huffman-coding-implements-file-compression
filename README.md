# 哈夫曼编码文件压缩工具

一个使用 **C++17** 实现的文件压缩与解压缩程序。项目基于哈夫曼编码，根据文件中各字节出现的频率构建哈夫曼树，将出现频率较高的字节转换为较短的编码，从而减少数据所占用的空间。

项目通过二进制文件读写处理数据，支持空文件、单一字节内容的文件，以及普通文本和其他二进制文件。

## 功能特点

- **文件压缩**：统计输入文件中 256 种字节的出现频率，构建哈夫曼树并生成编码表。
- **文件解压缩**：读取压缩文件中的频率表，重建哈夫曼树并恢复原始文件。
- **按位写入**：将哈夫曼编码转换为比特流，并打包成字节写入文件。
- **自定义文件格式**：保存文件标识、原始文件大小、字节频率表和末尾补位信息。
- **异常处理**：对文件打开失败、文件头不完整、格式标识错误和比特流不足等情况进行处理。
- **两种运行方式**：支持交互式菜单，也支持通过命令行参数执行压缩或解压缩。

## 技术与知识点

- **编程语言**：C++17
- **数据结构**：二叉树、链表、数组
- **算法**：贪心思想、哈夫曼编码、深度优先遍历
- **文件处理**：二进制文件读写、文件大小获取、文件指针定位
- **位操作**：比特流读写、按字节打包、末尾补位
- **C++ 标准库**：`std::array`、`std::list`、`std::string`、`std::vector`、文件流与异常处理

## 编译与运行

源代码文件名为 `源.cpp`。

### 使用 g++

在项目目录下打开终端，执行：

```bash
g++ -std=c++17 -O2 "源.cpp" -o huffman
```

Windows 下也可以生成 `huffman.exe`：

```bash
g++ -std=c++17 -O2 "源.cpp" -o huffman.exe
```

### 方式一：交互式菜单

直接运行程序：

```bash
./huffman
```

Windows 下运行：

```powershell
.\huffman.exe
```

根据菜单提示选择压缩或解压缩，然后输入源文件路径和目标文件路径。

### 方式二：命令行参数

压缩文件：

```bash
./huffman c input.txt output.huf
```

解压缩文件：

```bash
./huffman d output.huf restored.txt
```

其中：

- `c` 表示压缩，后面依次填写输入文件和输出压缩文件。
- `d` 表示解压缩，后面依次填写输入压缩文件和恢复后的输出文件。

在 Windows 中，将上述命令里的 `./huffman` 替换为 `huffman.exe` 即可。

## 压缩文件格式

生成的 `.huf` 文件包含以下内容：

| 内容 | 作用 |
| --- | --- |
| 文件标识 `HUF1` | 用于识别压缩文件格式 |
| 原始文件大小 | 记录解压缩时需要恢复的字节数 |
| 256 项字节频率表 | 用于重新构建哈夫曼树 |
| 末尾补位数 | 记录最后一个字节中补充的零位数 |
| 哈夫曼编码比特流 | 保存压缩后的数据 |

解压缩时，程序根据频率表重新构建与压缩阶段一致的哈夫曼树，并以记录的原始文件大小作为停止条件，避免把末尾补位误认为有效数据。

## 实现思路

1. **统计频率**：逐字节读取源文件，统计每种字节出现的次数。
2. **构建哈夫曼树**：按频率从小到大取出两个节点，合并为新节点，直到形成一棵完整的树。
3. **生成编码表**：从根节点开始遍历，向左记为 `0`，向右记为 `1`，为每个字节生成对应编码。
4. **写入压缩数据**：将编码逐位写入比特流，凑满一个字节后写入输出文件。
5. **恢复文件**：读取压缩文件头并重建哈夫曼树，逐位解码，直到恢复出指定数量的原始字节。

对于只包含一种字节的文件，程序约定该字节的编码为 `0`，并在解压缩时根据原始文件大小直接恢复内容。

## 注意事项

- 哈夫曼编码并不保证所有文件都能变小。对于很小或本身已压缩的数据，频率表等文件头开销可能使压缩文件反而更大。
- 当前文件格式直接写入整数的二进制表示，适合在兼容的运行环境中使用；若要实现跨平台、长期兼容的文件格式，可以进一步统一整数的字节序并增加完整性校验。
- 请将解压缩输出指定为不同于原始输入的重要文件路径，避免意外覆盖需要保留的数据。
